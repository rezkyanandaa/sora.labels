# sora.labels — GitHub Pages package

A responsive static storefront for sora.labels, styled as a soft Parisian knit boutique.

## Included
- `index.html`, `style.css`, `app.js`
- 12 locally stored image assets (11 product images + hero)
- Minimal favicon
- Responsive layout, product search/filter/sorting, wishlist, quick view, shopping bag saved in browser storage, WhatsApp checkout, and subtle Web Audio interaction sounds.

## Run locally
Open `index.html` in a browser. Internet is only needed for Google Fonts; all product photos are included locally.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload all files and the `assets` folder to the root of a GitHub repository.
3. In **Settings → Pages**, choose deploy from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish.
